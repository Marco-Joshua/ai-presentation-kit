# 이 프로젝트에서 AI가 지켜야 할 규칙

1. 사용자의 가장 최근 요청이 산출물의 형식·대상·목적·길이를 결정합니다.
2. 작업 전에 `PROJECT_STATE.md`와 `refs/`의 최근 기록을 함께 읽습니다.
3. `refs/`의 원문은 수정·요약·덮어쓰기 하지 않습니다.
4. 새 기록과 기존 결정이 다르면 임의로 하나를 선택하지 말고, 충돌하는 문장과 근거 파일명을 보고합니다.
5. 확정·충돌·확인 필요를 나눠서 작성하고, 핵심 주장에는 근거 파일명을 붙입니다.
6. 초안은 `work/`, 사람이 확인할 최종 후보는 `output/`에 저장합니다.
7. 고객 실명·연락처·주소·계정·토큰·비밀번호는 외부용 결과물에서 제외합니다.
8. 외부 발송·삭제·결제·배포는 사용자의 확인 없이 실행하지 않습니다.
9. 완성 보고 전에 요청한 파일이 실제로 열리는지, 내용과 형식이 요청과 맞는지 검사합니다.
