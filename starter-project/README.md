# AI 프로젝트 폴더 스타터 킷

이 폴더를 업무나 프로젝트별로 복사해 사용합니다. 폴더명은 고객명보다 `신규채용`, `월말보고`, `제품A-리뉴얼` 처럼 일을 구분할 수 있는 이름이 좋습니다.

AI에게 이렇게 요청해도 됩니다.

```text
starter-project 폴더를 [프로젝트명]으로 복사해줘.
내가 주는 회의록·메일·통화·메신저 기록을 refs/날짜/ 아래에 원문 그대로 넣어줘.
아직 산출물은 만들지 말고, 현재 파악한 맥락과 확인할 일만 보고해줘.
```

## 폴더 구조

```text
project/
├── AGENTS.md          AI가 지켜야 할 작업 규칙
├── PROJECT_STATE.md   사람이 승인한 현재 상태
├── refs/              메일·회의·통화·메신저 원문
├── assets/            사진·스크린샷·로고·도해
├── work/              AI가 만든 작업 중 초안
└── output/            사람이 확인할 최종 후보
```

## 운영 원칙

1. `refs/`의 원문은 고치지 않습니다.
2. 새 정보가 기존 결정과 다르면 `PROJECT_STATE.md`에 충돌으로 남깁니다.
3. 사람이 승인한 내용만 현재 결정으로 올립니다.
4. AI는 `work/`와 `output/`에만 산출물을 만듭니다.
5. 외부 발송·삭제·결제·배포는 사람의 확인 후에만 합니다.
