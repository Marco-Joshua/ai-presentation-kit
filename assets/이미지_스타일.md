# 이미지 에셋 스타일 — 이 키트의 그림은 전부 이 규격을 따릅니다

장표에 넣을 도해·일러스트를 AI(코덱스 등 이미지 생성이 되는 도구)가 만들 때의 기준입니다.
`assets/샘플_도해_*.png`가 이 규격으로 만들어진 견본입니다.

## 규격

- **글자·숫자·문자를 절대 넣지 않는다.** 라벨 없는 순수 도형과 선만. (한글이 깨지기 때문)
- 흰 배경 · 가로 1000 × 세로 700
- 얇고 균일한 선 굵기의 **평면 벡터풍 선 도해**. 그림자·그라데이션·3D·질감 금지
- 색은 최대 4가지: 진한 잉크색 `#0b0b0c` · 중간 회색 `#5e5f66` · 연한 회색 `#c9cdd6` · 포인트 1색(장표의 --accent와 동일)
- 채우기는 최소, 윤곽선 위주. 여백을 넉넉히 — 도형이 가장자리에 닿지 않게

## 생성을 요청하는 법 (프롬프트 틀)

```
[무엇을 표현하는지 한 문장]을 표현하는 선 도해 이미지를 만들어 assets/ 에 저장해 주세요.
- 글자·문자·숫자 금지, 흰 배경, 1000×700
- 얇은 균일 선의 평면 벡터풍, 그림자·그라데이션 금지
- 색: #0b0b0c / #5e5f66 / #c9cdd6 (+ 포인트색 하나)
- 만든 뒤 이미지를 직접 열어 글자 비슷한 것이 보이면 다시 만들어 주세요
```

## 우선순위

1. **refs나 assets에 사용자가 넣어둔 실제 사진·스크린샷이 있으면 그것을 먼저 쓴다**
2. 없고, 도구가 이미지 생성을 지원하면 위 규격으로 생성한다
3. 생성도 안 되면 점선 플레이스홀더(`shot-fit ph`)로 자리만 잡고 무엇이 들어갈지 적어둔다
