# AI 프로젝트 폴더 · 발표 자료 제작 키트

**2026-08-27 ASC 라이브 특강 「설치는 끝났다. 이제 뭐하지..?」 참석자용**

회의·메일·통화·메신저 기록을 프로젝트별로 남기면 AI가 그 맥락을 읽고 일일보고 초안, 주간보고 장표·PDF, 브리핑 영상까지 만들도록 돕는 실행형 키트입니다.

코덱스처럼 이미지 생성이 가능한 도구는 필요한 장면 에셋까지 만들 수 있습니다. 유료 TTS나 별도의 고가 영상 서비스 없이도 로컬 음성과 동적 영상 엔진을 설치해 완주할 수 있습니다.

## 5분 안에 시작하기

### 1. 프로젝트 폴더를 복사합니다

코덱스 또는 클로드 코드에게 이렇게 말합니다.

> `starter-project` 폴더를 `[내 업무명]`으로 복사해줘.

### 2. 원문을 넣습니다

`refs/날짜/`에 회의록·메일·통화·메신저·사진을 넣습니다. 원문은 수정하지 않고, 새 기록이 기존 결정과 다르면 둘 다 근거로 남깁니다.

`refs/20260814/`에는 강의에서 설명한 메일·문자/카톡·온라인 회의 STT·오프라인 회의 STT·전화 기록과 메일 첨부 PDF의 가상 예시가 들어 있습니다. 저장소를 받은 즉시 이 기록으로 주간보고·장표·영상을 만들어 볼 수 있습니다. 실제 업무는 `starter-project/`를 복사해 시작하세요.

### 3. 시작 문장을 붙여넣습니다

`시작_문장_3종.md`에서 상황에 맞는 문장을 복사합니다. 명령어를 외우거나 코드를 직접 고칠 필요는 없습니다.

## 폴더가 AI의 기억이 되는 구조

```text
원문을 refs/날짜/에 보존
        ↓
PROJECT_STATE.md에 승인된 현재 상태를 정리
        ↓
새 세션은 원문과 현재 상태를 함께 확인
        ↓
일일보고 초안 · 주간보고 HTML/PDF · 브리핑 영상
```

- `refs/`의 원문은 고치지 않습니다.
- `PROJECT_STATE.md`에는 사람이 확인한 현재 상태만 적습니다.
- 새 기록이 예전 결정과 충돌하면 덮어쓰지 않고 사람에게 확인을 요청합니다.
- 산출물은 `output/`에 따로 저장하고 사람이 보내기 전에 확인합니다.
