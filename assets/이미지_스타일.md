# 이미지 에셋 스타일 — 실제 화면과 생성 이미지를 함께 씁니다

코드로 그린 도형만 반복하면 결과물이 쉽게 ‘AI가 만든 피피티’처럼 보입니다.
아래 우선순위대로 실제 화면과 이미지 생성 결과를 섞어 씁니다.

## 에셋 우선순위

1. `refs/`와 `assets/`에 있는 실제 사진·스크린샷
2. 슬랙·노션·깃허브처럼 공개된 서비스의 공식 로고
3. 이미지 생성이 가능한 코덱스라면 장면의 의미를 보완하는 편집 일러스트
4. HTML/CSS 도형은 숫자·선·간단한 도식에만 사용

실제 화면에 이름·전화번호·메일·고객사명·주소가 있으면 원본을 직접 쓰지 않고
복사본을 만든 뒤 읽을 수 없게 마스킹합니다.

## 생성 이미지 규격

- **글자·숫자·문자를 절대 넣지 않는다.** 라벨 없는 순수 도형과 선만. (한글이 깨지기 때문)
- 흰 배경 · 가로 1000 × 세로 700
- 깔끔한 편집 일러스트 또는 콜라주. 장면마다 구도와 크롭을 다르게 한다
- 불필요한 3D 아이콘·유리 카드·과한 그림자·무의미한 장식은 금지
- 색은 최대 4가지: 진한 잉크색 `#0b0b0c` · 중간 회색 `#5e5f66` · 연한 회색 `#c9cdd6` · 포인트 1색(장표의 --accent와 동일)
- 채우기는 최소, 윤곽선 위주. 여백을 넉넉히 — 도형이 가장자리에 닿지 않게

## 이미지 생성 프롬프트 틀

```
[무엇을 표현하는지 한 문장]을 보여주는 편집 일러스트를 만들어 assets/ 에 저장해 주세요.
- 글자·문자·숫자 금지, 흰 배경, 1000×700
- 검정과 회색을 중심으로 하고 포인트색은 하나만 사용
- 군더더기 없는 매거진 편집 디자인, 넉넉한 여백, 명확한 시선 흐름
- 흔한 3D 아이콘 묶음, 둥근 카드 그리드, 장식용 그래프 금지
- 색: #0b0b0c / #5e5f66 / #c9cdd6 (+ 포인트색 하나)
- 만든 뒤 이미지를 직접 열어 글자 비슷한 것이 보이면 다시 만들어 주세요
```

생성 도구가 없으면 임의의 저품질 그림을 만들지 않습니다. 실제 화면을 더 크게 쓰거나
타이포그래피 장면으로 전환하고, 필요한 에셋만 `TODO`로 명시합니다.
