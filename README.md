# AI 발표 자료 제작 키트

**2026-08-27 ASC 오픈 특강 「설치는 끝났다. 이제 뭐하지..?」 참석자용**

강의에서 보여드린 일하는 구조를 그대로 담은 5개 파일입니다.
Codex, Claude Code 등 폴더를 읽을 수 있는 AI 도구라면 무엇이든 쓸 수 있습니다.

## 구성

| 파일 | 용도 |
|---|---|
| `AGENTS.md` | 이 프로젝트에서 AI가 지켜야 할 규칙 |
| `PROJECT_STATE.md` | 원문·결정·현재 상태를 나눠 적는 상태 파일 |
| `01_읽기.md` | 새 세션을 여는 첫 프롬프트 |
| `02_만들기.md` | 발표 자료(장표·PDF·영상 대본)를 만드는 프롬프트 |
| `03_검사.md` | 완성물을 납품 전에 검사하는 프롬프트 |
| `장표_템플릿.html` | 장표 디자인 템플릿 — 브라우저로 열어 미리 보세요 |
| `04_영상.md` | 장표에 목소리·자막을 붙여 영상으로 만드는 법 |
| `scripts/make_video.py` | 영상 제작 스크립트 (무료 TTS · 목소리 선택 가능) |
| `assets/` | 장표에 바로 쓸 수 있는 샘플 도해 |

## 시작하는 법

**코덱스(또는 Claude Code)를 열고 이 레포 주소를 붙여넣으며 "이거 받아서 설치해줘"라고 하세요.**
설치가 끝나면 AI가 다음 할 일을 안내합니다. 자세한 대화 예시는 `사용_시나리오.md`에 있습니다.

직접 하고 싶다면: 이 폴더를 내려받아 AI 도구로 열고, `refs/날짜/` 폴더에
회의록·메일을 넣은 뒤 `01_읽기.md`의 프롬프트를 붙여넣으면 됩니다.

AI가 현재 상태를 정확히 말하는 것부터 성공시키세요. 결과물은 그다음이 훨씬 쉽습니다.

## 순서가 곧 사용법입니다

```
자료를 refs에 쌓는다 → 01 읽기 → 02 만들기 → 03 검사 → 사람이 승인한다
```

- 프롬프트를 그대로 쓰지 마시고, `[대괄호]` 부분만 여러분 업무로 바꾸세요.
- 고객 자료·개인정보·비밀번호는 회사 정책과 AI 계정의 보안 범위를 먼저 확인하세요.
- 최종 발송·배포 판단은 항상 사람이 합니다.
