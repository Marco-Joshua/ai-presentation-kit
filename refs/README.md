# refs — 업무 원문을 여기에 넣으세요

회의 전사·메일·통화 요약·메신저·사진을 이벤트가 발생한 날짜 폴더에 저장합니다.

```text
refs/
└── 20260827/
    ├── 20260827_킥오프_STT.txt
    ├── 20260827_범위변경_메일.txt
    ├── 20260827_담당자_통화.txt
    └── 20260827_결정사항_메신저.txt
```

## 보관 규칙

- 원문은 수정하지 않습니다. 틀린 내용을 발견하면 정정 기록을 새 파일로 남깁니다.
- 업무에 영향을 주는 요청·변경·확정 내용만 남깁니다.
- 사적인 대화와 불필요한 개인정보, 계정·비밀번호·토큰은 저장하지 않습니다.

완주 예제에 사용하는 가상 원문은 `examples/weekly-report-20260814/refs/`에 따로 있습니다. 예제가 새 업무의 맥락으로 읽히지 않도록 루트 `refs/`와 분리했습니다.

## 샘플 기록

`샘플_기록/20260814/`에는 아래 다섯 종류의 가상·비식별 예시가 있습니다.

- 메일
- 문자·카카오톡
- 온라인 회의 STT
- 오프라인 회의 STT
- 전화 통화 기록

이 파일은 형식 참고용입니다. AI는 사용자가 샘플 실행을 명시한 경우에만 읽고, 일반 업무 요청에서는 근거로 사용하지 않습니다.
