## 시작하는 법 — 오늘 10분

1. 업무 프로젝트 폴더를 하나 만듭니다. 그 안에 `refs` 폴더를 만듭니다.
2. 이 키트의 `AGENTS.md`와 `PROJECT_STATE.md`를 복사해 넣고, 예시를 지우고 여러분 내용으로 바꿉니다.
3. 오늘 받은 메일 하나, 회의 메모 하나를 `refs/20260827/` 처럼 날짜 폴더에 넣습니다.
4. AI 도구에서 이 폴더를 열고 `01_읽기.md`의 프롬프트를 붙여넣습니다.

AI가 현재 상태를 정확히 말하는 것부터 성공시키세요. 결과물은 그다음이 훨씬 쉽습니다.
