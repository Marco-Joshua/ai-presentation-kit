# refs — 업무 원문을 여기에 넣으세요

회의 전사·메일·통화 요약·메신저·사진을 이벤트가 발생한 날짜 폴더에 저장합니다.

```text
refs/
└── 20260827/
    ├── 20260827_킥오프_STT.txt
    ├── 20260827_범위변경_메일.txt
    ├── 20260827_담당자_통화.txt
    └── 20260827_결정사항_메신저.txt
```

## 보관 규칙

- 원문은 수정하지 않습니다. 틀린 내용을 발견하면 정정 기록을 새 파일로 남깁니다.
- 업무에 영향을 주는 요청·변경·확정 내용만 남깁니다.
- 사적인 대화와 불필요한 개인정보, 계정·비밀번호·토큰은 저장하지 않습니다.

실행할 때는 현재 시스템 날짜를 먼저 확인합니다. `오늘`이라는 요청은 같은 날짜의 폴더만 읽고, 주간보고는 그 주 월요일부터 기준일까지 읽습니다. 미래 날짜 폴더는 결과에 포함하지 않습니다.

완주 예제에 사용하는 가상 원문은 `examples/weekly-report-20260814/refs/`에도 따로 있습니다.

## 포함된 실습 기록

`20260814/`에는 아래 다섯 종류의 가상·비식별 예시가 있습니다.

- 메일
- 문자·카카오톡
- 온라인 회의 STT
- 오프라인 회의 STT
- 전화 통화 기록
- 메일과 연결된 PDF 첨부파일

`20260825/`와 `20260827/`은 같은 MARCO 고객지원 개선 프로젝트가 이어지는 시연 데이터입니다.

- `20260825/`: 문의 분석, 도움말·답변 템플릿 준비, 모바일 로그인 이슈 발견
- `20260827/`: 도움말·템플릿 적용, 문의·응답 시간 개선, 모바일 수정 배포
- 각 날짜의 `첨부/`: 수치 CSV와 개선안·배포 체크리스트

이 저장소에서 주간보고·장표·영상을 요청하면 AI가 이 파일을 함께 읽어 결과물을 만듭니다. 실제 업무에서는 `starter-project/`를 복사하고 새 프로젝트의 `refs/YYYYMMDD/`에 기록을 넣으세요.
